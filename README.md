🐜 NYC Ant Defenders
An action web game built with HTML5 Canvas, Web Audio API, and Speech Synthesis. Defend the streets of New York City against giant crawling ants!
🎮 Playable Characters
Rumi: Purple braided ponytail with yellow jacket. Uses a sword for fast close-range slashes.
Mira: Long magenta hair with twin pigtails & blue ribbons. Uses a long-reach spear thrust.
Fona: Short dark hair with bun & teal crop top. Throws unlimited flying katanas at street level.
✨ Features
Phone Aspect Ratio Frame: Designed for a modern mobile smartphone view.
Synthesized Audio: Web Audio API sound effects for slashes, thrusts, hits, and damage.
Speech Synthesis: Speaks out loud only the numerical score whenever an ant is defeated.
Responsive Controls: Tap or click anywhere to execute attacks.
Character Select Screen: Change characters at the main menu or from the game over screen via the Blue Change Character Button.
🚀 How to Play
Tap on your chosen hero from the selection screen.
Tap anywhere on the screen to strike or throw katanas as crawling ants approach.
Prevent the ants from reaching your defender!
📦 How to Deploy on GitHub Pages
Push this repository to GitHub.
Navigate to Settings > Pages.
Under Build and Deployment, set Source to Deploy from a branch and select main (root).
Save and view your live game!
